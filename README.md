# Financial-Dashboard-PowerBI
Interactive financial dashboard built with Power BI and Excel data analysis.
> An interactive financial dashboard built with **Power BI**, backed by a structured **Excel dataset** — designed to surface key business metrics, trends, and insights at a glance.

## 🗂️ Files Overview
 
### `Financial_Dashboard.pbix` — Power BI Dashboard
An interactive report built in **Microsoft Power BI** that visualizes the financial dataset through charts, KPI cards, slicers, and trend analyses.
 
| Detail | Info |
|---|---|
| Tool | Microsoft Power BI Desktop |
| Format | `.pbix` |

The raw financial data used as the data source for the Power BI dashboard. Contains structured records for financial performance analysis.
 
| Detail | Info |
|---|---|

## 🚀 Getting Started
 
### Step 1 — View the Dashboard (Power BI)
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) *(free)*
2. Clone or download this repository
3. Open `Financial_Dashboard.pbix` in Power BI Desktop
4. Explore the interactive visuals, filters, and insights
 
### Step 2 — Explore the Raw Data (Excel)
1. Extract Excel on your computer from `Financial_Dataset.zip` and open in **Microsoft Excel** or **Google Sheets**
2. Review the dataset structure and fields
3. Use built-in Excel tools for additional filtering or pivot analysis
